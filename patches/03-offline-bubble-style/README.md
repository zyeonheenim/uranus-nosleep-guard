# 03 · 线下剧情 · 气泡样式 (bubble-style)

> 依赖：02｜基线：Uranus 1.22.3｜改动：3 个文件（其中 `server/src/bubblestyle.js` 是新增）

**一句话**：两侧气泡的底色、边框、文字色、圆角分开调，**存服务端** —— 手机上调完，电脑上一样。

---

## 它治什么

两件事：

1. **样式改不了。** 原版线下气泡跟着主题走，你只能换整套主题。想「我这侧浅灰、他那侧米白、
   圆角 18、边框淡一点」做不到。
2. **改了也白改。** 早期实现把样式存在 `localStorage` 里，结果手机上调好的配色，电脑上永远不生效。

第 2 条不是 bug 是机制：`localStorage` 按「设备 + 浏览器 + **源站**」三者隔离。
手机用 `http://192.168.1.8:8787` 打开、电脑用 `http://127.0.0.1:8787` 打开，
**源站不同 → 两份存储，永不互通**。所以样式必须放到服务端。

---

## 装上之后

线下页顶部多一个 **样式** 按钮，打开是：

```
┌─ 气泡样式 ──────────────────────────────┐
│  [预览区]  你：……        他：……          │  ← 跟着下面的改动实时变
│                                          │
│  ( ) 跟随主题    (●) 自定义               │
│  [ 用户侧 ] [ 助手侧 ]                    │
│  背景颜色   ■  #f4f4f5                    │
│  背景不透明度 ───────●────  100%          │
│  边框颜色   ■  #d8d8d8                    │
│  边框不透明度 ─────●──────  100%          │
│  边框宽度   ──●───────────  1.0           │
│  文字颜色   ■  #3f3f3f                    │
│  圆角半径   ─────●────────  12            │
│  恢复默认                                 │
└──────────────────────────────────────────┘
```

- 改完**即时生效**，没有「保存」按钮 —— 关掉就是存好了
- 「跟随主题」时**一个样式都不盖**：换主题、换类名都不受影响，等于没装过这个功能
- 「恢复默认」= 回到跟随主题

## 机制

| 位置 | 作用 |
|---|---|
| `data/offline-bubbles.json` | 真值。**不走 `config.json`** —— 老坑：控制台一保存就整包覆盖磁盘，UI 偏好会被冲掉 |
| `server/src/bubblestyle.js` | `GET/PUT /api/offline-bubbles`，落盘前过一遍白名单 |
| `client/.../offline.jsx` | 读回来先本地缓存一份（打开瞬间不该闪默认样式），改完防抖 400ms PUT |

**白名单清洗**（`sanitizeBubbleStyle`）—— 服务端不信前端：

- 只留 `mode` + `user` + `assistant`，其余字段一律丢掉
- 颜色只认 6 位 hex（统一转小写）；圆角 0–40、边框宽 0–12、不透明度 0–100，越界夹回
- 空 body → 400；超过 20KB → 400

**主题模式怎么实现**：自定义颜色用**内联 style** 盖在气泡上（内联天然压过 Tailwind 类，
不用去拆类名）；`mode === "theme"` 时返回 `null`，等于什么都不做。

**两台设备怎么同步**：读写都走服务端那份。本地缓存只在「刚打开、还没拿到服务端值」时先画出来，
拿到之后以服务端为准；拿到之前**禁止回推**，否则会用本地旧值把另一台刚改好的盖掉。

```bash
node uninstall.mjs --run
```

```bash
cd /path/to/Uranus_Imessage
patch -p1 < /path/to/patches/02-offline-version-history/02-version-history.patch
patch -p1 < /path/to/patches/03-offline-bubble-style/03-bubble-style.patch

```

## 限制

- 样式是**整机一份**，不按角色分开（想要「每个角色不同配色」得改存储结构）
- 备份 Uranus 时记得一起备份 `data/offline-bubbles.json`
- 只作用于线下剧情气泡；线上 iMessage 气泡不受影响
